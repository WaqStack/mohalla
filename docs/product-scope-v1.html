01

Executive Summary

We are building an Android-first bilingual civic community platform that lets citizens across Pakistan discover awareness content, discuss local issues, connect with each other and with civic organizations, and gather at community events — in Urdu or English, their choice.

This is not a general-purpose social network and not an entertainment app. It is a mobilization platform: awareness → discussion → connection → participation.

Version 1 delivers
  • Android application
  • Admin Web Portal
  • Full Urdu + English interface with right-to-left layout
  • 88 must-have features across 15 modules
Version 1 deliberately excludes
  • iOS and public web
  • Video posts and in-app video calling
  • Groups, group chat, and polls
  • Marketplace, advertising, and monetization
02

Product Vision

A bilingual mobile community platform that allows citizens across Pakistan to share civic awareness, connect with people and organizations working on the same issues, and come together at community events — in Urdu or English.

Positioning · Facebook is where you scroll. This is where you act.
03

Problem Statement

Pakistani civic communities coordinate today through WhatsApp groups and shared phone numbers. That model fails them in six specific ways.

What breaksConsequence
WhatsApp content is unsearchable and disappearsAwareness material is shared once, then lost forever
No threading — every topic collides in one streamSerious discussion is impossible
1,024-member cap per groupCommunities fragment into dozens of disconnected groups
Phone numbers exposed to strangersSerious safety and privacy risk, especially for women
No moderation toolsSpam, harassment, and misinformation spread unchecked
Nothing is permanent or discoverableNew members join with zero context

Why existing platforms don't fill the gap

PlatformWhy it fails this audience
Facebook / TikTokOptimized for entertainment; civic content drowns in the algorithm
Twitter / XEnglish-first, low Pakistani penetration, hostile discourse
LinkedInProfessional only, English-first, no community or civic layer
All of themEnglish-first, poor Urdu support, no right-to-left native experience
Solution. A permanent, searchable, moderated, Urdu-native home for civic awareness and community action — where content persists, people are findable, organizations are verifiable, discussion is threaded, and gatherings are organized.

Target Users

Civic-Minded Citizen Primary
DescriptionOrdinary Pakistani adult. Android user, Facebook-literate, comfortable in Urdu and/or English. All age groups, nationwide.
Main needKnow what is happening in my community; find people who care about the same issues; participate.
Main activitiesRegister, build profile, browse feed, read awareness content, follow people and organizations, post, comment, like, message, RSVP to events
PermissionsFull standard user permissions
Verified Organization Secondary
DescriptionNGO, community group, or civic institution. In Version 1 this is a normal user account carrying a verified badge — not a separate page system.
Main needDistribute awareness material credibly; announce and fill events; build a following.
Main activitiesEverything a citizen can do, plus: carries a verified badge, creates events, is discoverable as an organization
PermissionsStandard user + verified badge + organization account flag
Platform Administrator Essential
DescriptionShehersaaz team member operating the Admin Web Portal. Small trusted group.
Main needKeep the platform safe, credible, and active.
Main activitiesReview reports, remove content, suspend users, publish official announcements, verify organizations, monitor platform health
PermissionsFull moderation and administration. All admins have equal power in Version 1.
Deliberately not created: Moderator, Expert, Journalist, Government, and Volunteer roles. Three roles is the minimum that works. Every extra role multiplies permission logic, testing, and admin interface. Role granularity belongs in Phase 2, driven by real operational pain rather than speculation.

Core User Journey

7.1 — New citizen · first-time experience
Opens app
   │
   ├─▸ Chooses language        Urdu / English — the first screen, before anything else
   │
   ├─▸ Registers with phone number
   ├─▸ Verifies via OTP
   ├─▸ Confirms age 13+ · Accepts Terms and Community Guidelines
   │
   ├─▸ Creates profile         name · photo · city · bio · individual or organization
   │
   ├─▸ SUGGESTED ACCOUNTS      cold-start critical — pre-seeded orgs and active users
   ├─▸ Follows 3–5 accounts
   │
   ├─▸ Lands on FEED
   │      ├── Featured / Announcements   admin-curated, always populated
   │      └── Following feed             newest first
   │
   ├─▸ Reads awareness post · Likes · Comments
   ├─▸ Receives notification when someone replies
   └─▸ Returns to app
7.2 — Active citizen · recurring loop
Push notification ─▸ Opens app
   │
   ├─▸ Reads feed ──┬─▸ Likes / Comments
   │                ├─▸ Opens Discover, follows new people
   │                ├─▸ Searches for a topic or person
   │                └─▸ Sends a direct message
   │
   ├─▸ Creates a post          text · image · PDF · link
   │
   └─▸ Sees an EVENT ─▸ Taps RSVP ─▸ Gets reminder notification
          │
          └─▸ On event day ─▸ Taps "Join Meeting"
                                 └─▸ Opens Zoom / Meet externally
                                     or shows the physical location
7.3 — Safety journey · encountering harmful content
Sees harmful post
   │
   ├─▸ Taps ⋯ ─▸ Report ─▸ selects a reason
   │
   ├─▸ Post reaches 3 reports from 3 different users
   │
   ├─▸ AUTOMATICALLY HIDDEN from all feeds — no admin wait
   │
   ├─▸ Enters the Admin Moderation Queue
   │      └─▸ Admin restores it, or deletes it permanently
   │
   └─▸ Reporter can also BLOCK the user
          └─▸ blocked user cannot see, follow, comment on, or message them
7.4 — Administrator journey
Logs into Admin Web Portal
   │
   ├─▸ Dashboard    open reports · new users · posts today
   │
   ├─▸ MODERATION QUEUE ─▸ Review auto-hidden content
   │        ├─▸ Restore            false report
   │        └─▸ Delete permanently
   │               └─▸ Optionally suspend or ban the author
   │
   ├─▸ USERS ─▸ Search ─▸ View activity ─▸ Suspend / Ban / Reinstate
   │
   ├─▸ ANNOUNCEMENTS ─▸ Write ─▸ Publish to Featured section
   │                              └─▸ Push notification to all users
   │
   └─▸ VERIFICATION ─▸ Review request ─▸ Grant or revoke verified badge

Admin Requirements

Operational model

  • Admin Web Portal with an English-only interface — deliberate, since admins are Shehersaaz staff
  • Small trusted admin group; accounts created manually
  • All admins have equal permissions in Version 1 — no role hierarchy
  • Target: the moderation queue is reviewed at least once daily

Day-one capabilities

RequirementDetail
Moderation queueAll auto-hidden and reported content, sorted by report count and age

Safety & Moderation Requirements

The model — post-moderation with automated threshold hiding

User publishes post ─▸ LIVE IMMEDIATELY   no approval delay
        │
        ├─▸ Users report it
        │
        ├─▸ 3 reports from 3 DISTINCT users
        │        │
        │        ├─▸ AUTO-HIDDEN from all feeds
        │        └─▸ Author is notified
        │
        └─▸ Enters the Admin Moderation Queue
                 ├─▸ RESTORE                 false report
                 └─▸ DELETE PERMANENTLY
                          └─▸ Optional: suspend or ban the author
Why this design
  • Harmful content disappears in minutes without waiting for an admin
  • A human always makes the permanent decision — a legitimate citizen complaint is never auto-deleted
  • Near-zero recurring cost; about one dev-day to build
  • Requiring three distinct accounts resists trivial gaming
Privacy commitments
  • Phone numbers are never shown to other users — used only for authentication
  • This is the single most important privacy improvement over the WhatsApp status quo
  • Deleting an account removes personal data; content is deleted or anonymized
  • No location tracking in Version 1
